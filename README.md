# QuickMath - Practice Your Math Facts

A fast-paced, interactive web app designed to help students practice multiplication and division facts. Perfect for building math fluency and confidence!

##  Try It Now

Visit the app at: https://mordric.github.io/FactFamilyQuickPractice/

##  Features

### Core Functionality
- **Interactive Practice**: Answer math problems using an easy-to-use number pad interface
- **Instant Feedback**: Get immediate visual feedback on your answers
- **Comprehensive Coverage**: Practice multiplication and division facts from 0×0 through 12×12
- **Customizable Practice**: Choose exactly which fact families and equations you want to practice

### Advanced Features
- **Answer Timer**: Set a time limit for answering each question (1-60 seconds)
- **Practice Time Limit**: Set a total practice duration (1-120 minutes)
- **Goal Setting**: Set a target number of correct answers to reach
- **Mastery System**: Automatically remove equations once they're mastered (answered correctly multiple times in a row)
- **Persistent Mastery**: Option to permanently skip mastered equations in future sessions
- **Detailed Statistics**: Track your performance for each equation with accuracy percentages and visual progress bars

##  Settings & Configuration

### Problem Types
Choose which types of problems to practice:
- **Multiplication Only**: Practice only multiplication facts (e.g., 3 × 4 = ?)
- **Division Only**: Practice only division facts (e.g., 12 ÷ 3 = ?)
- **Both**: Practice a mix of multiplication and division

### Fact Families
- Select individual fact families (e.g., 3 × 4 family)
- Use **Select/Deselect All** to quickly toggle all families
- Expand each family to enable/disable individual equations

### Timer Settings
**Answer Timer**: Set a time limit for each question
- Check the box to enable
- Set duration from 1-60 seconds
- Questions automatically marked wrong if time expires

### Finish Conditions
Set goals to end your practice session automatically:

**Practice Time Limit**
- End practice after a set duration
- Range: 1-120 minutes
- Shows countdown timer during practice

**Correct Answers Goal**
- End practice after reaching a target number of correct answers
- Range: 1-500 correct answers
- Shows remaining answers needed during practice

**Mastery Check**
- Automatically remove equations once mastered
- Set how many consecutive correct answers = mastered (1-20)
- **Persistent Mode**: Mastered equations stay removed in future sessions
- View and reset mastered equations in the Statistics screen

## ?? Statistics

The Statistics screen provides detailed insights into your practice:

### Overall Progress
- **Total Asked**: Total number of questions answered
- **Total Correct**: Total number of correct answers
- **Overall Accuracy**: Your accuracy percentage across all problems

### Individual Problem Statistics
- Each equation shows:
  - Number of times asked
  - Number of correct answers
  - Accuracy percentage with color-coded progress bar
    - Red: < 60% accuracy
    - Orange: 60-79% accuracy
    - Green: 80%+ accuracy
- Problems sorted by accuracy (lowest to highest) to help you identify areas needing practice

### Mastered Equations
- View all equations you've mastered
- Permanently mastered equations (saved between sessions) are highlighted in blue
- Reset permanently mastered equations if you want to practice them again

### Reset Statistics
Use the **Reset All Statistics** button to clear all practice data and start fresh.

## ?? Data Storage

All data is stored locally in your browser using localStorage:
- Your selected fact families and settings
- Practice statistics for each equation
- Permanently mastered equations (if enabled)

**Note**: Clearing your browser data will erase your statistics and settings.

## ?? Tips for Effective Practice

1. **Start Small**: Begin with easier fact families (0-5) before moving to harder ones
2. **Use the Timer**: Challenge yourself with a time limit to build speed
3. **Set Goals**: Use the correct answers goal to maintain focus during practice
4. **Enable Mastery Mode**: Let mastered equations drop out so you can focus on the ones you need to practice
5. **Check Your Stats**: Review your statistics regularly to identify which facts need more practice
6. **Practice Regularly**: Short, frequent practice sessions are more effective than long, infrequent ones
